# Blue/Green Deployment Lab

A hands-on DevOps project demonstrating Blue/Green deployment using:

- AWS EC2
- Docker
- Kubernetes / k3s
- GitHub Actions
- Nginx
- PostgreSQL
- Prometheus
- Grafana

## Application

A simple Node.js application used to demonstrate containerization,
CI/CD, Kubernetes deployment, and Blue/Green deployment.
